# Free PC Game Distribution Platforms (No Upfront Cost)

> Research date: 2026-07-29
> Goal: Identify PC game stores that require **zero upfront payment** to upload/publish a game (no Steam Direct–style fee).

---

## 1. itch.io

| Attribute | Detail |
|-----------|--------|
| **Free to upload?** | **Yes.** Creating pages and uploading content costs nothing. No submission fee. |
| **Revenue share** | **Open revenue sharing** — you choose the % that goes to itch.io, from **0% to 100%**. Default is 10%. |
| **Annual / per-app fees** | None. |
| **Payment processing** | $0.30 + 2.9% per transaction (PayPal or Stripe). Payouts via PayPal or Payoneer; min. $5 USD. |
| **Review process** | **None.** Open publishing — upload immediately, no curation. |
| **Worth using?** | **Yes.** Most popular indie game jam platform (Ludum Dare, GMTK, Global Game Jam). Good discoverability via tags, collections, and jams. Audience skews older and is willing to pay for indie games. Revenue terms are the most developer-friendly of any store. |
| **Primary source** | [itch.io Creator FAQ](https://itch.io/docs/creators/faq) · [Payments & Revenue Share](https://itch.io/docs/creators/payments) |

---

## 2. Game Jolt

| Attribute | Detail |
|-----------|--------|
| **Free to upload?** | **Yes.** Upload a game page and free downloads at no cost. To sell, you need an approved Marketplace account (free to apply). |
| **Revenue share** | Developer sets the % shared with Game Jolt, **capped at 10% max** to the platform. |
| **Annual / per-app fees** | None. |
| **Payment processing** | Standard processor fees apply (PayPal). No monthly/annual fees. |
| **Review process** | Marketplace account requires approval; game pages themselves are not curated. |
| **Worth using?** | **Yes, as secondary.** Younger audience (teens/early 20s). Stronger community/social features than itch.io. Good for free-to-play, community-driven, or browser games. |
| **Primary source** | [Game Jolt Marketplace](https://ssr.gamejolt.net/marketplace) · [Add Your Game docs](https://gamejolt.com/help-docs/creators/add-game) · [Community confirmation of no fees](https://gamejolt.com/f/is-it-free-to-upload-pay-to-play/251346) |

## 3. GOG (Good Old Games)

| Attribute | Detail |
|-----------|--------|
| **Free to upload?** | **Free to submit** via the indie submission form. However, acceptance is **curated** — not guaranteed. No submission fee. |
| **Revenue share** | **70/30** (developer gets 70%). Option for an advance (60/40 until recouped, then 70/30). |
| **Annual / per-app fees** | None. |
| **Payment processing** | Bank transfer; fees deducted by intermediary banks. Min. payout threshold **$500 USD**. |
| **Review process** | **Curated.** Submit via [lp.gog.com/submit-your-game/en](https://lp.gog.com/submit-your-game/en); GOG reviews and decides. Estimated ~2-week response. |
| **Worth using?** | **Only if accepted.** DRM-free requirement. Lower discoverability than Steam but loyal, quality-focused userbase. Good for polished indie titles that fit the GOG catalog. |
| **Primary source** | [Submit your game on GOG](https://lp.gog.com/submit-your-game/en) · [GOG Developer Docs — Getting Started](https://docs.gog.com/quick-start/) · [GOG Indie submission page](https://www.gog.com/indie) · [Polygon on GOG indie portal](https://www.polygon.com/2013/8/20/4638584/gog-com-launches-submission-portal-for-indie-devs) |

## 4. Epic Games Store

| Attribute | Detail |
|-----------|--------|
| **Free to upload?** | **No — $100 submission fee per product** (recoupable after earning $1,000 in revenue on EGS). |
| **Revenue share** | **100% on first $1M net revenue per product per year**, then 88%/12% standard. (As of June 2025). |
| **Annual / per-app fees** | Submission fee is a one-time $100 per product (recoupable). No annual fees. |
| **Payment processing** | $100 min. payout threshold. Payment processor fees deducted before revenue share. |
| **Review process** | **Curated.** Self-service publishing tools available, but Epic reviews each submission (2–4 weeks). |
| **Worth using?** | **Not zero-cost upfront** due to the $100 fee. However, the fee is recoupable. Great revenue share terms for successful games. 295M+ user base. Best for high-quality, visually striking titles. |
| **Primary source** | [EGS self-service distribution page](https://store.epicgames.com/en-US/distribution) · [Submission fee docs](https://dev.epicgames.com/docs/epic-games-store/publishing-tools/organization-management/manage-org) · [Revenue share announcement](https://store.epicgames.com/en-US/news/epic-games-store-updates-revenue-share-keep-100-of-the-first-1m-per-product-per-year) |

## 5. Microsoft Store (PC)

| Attribute | Detail |
|-----------|--------|
| **Free to upload?** | **Yes for individuals** — the $19 registration fee has been waived for Individual accounts via the new flow at [storedeveloper.microsoft.com](https://storedeveloper.microsoft.com). **Company accounts cost ~$99 one-time.** |
| **Revenue share** | **88/12** (developer gets 88%) as of August 2021 for PC games. |
| **Annual / per-app fees** | None after initial account fee (free for individuals). |
| **Payment processing** | Standard Microsoft Store terms; payout thresholds apply. |
| **Review process** | **Certification required** (automated + human review). Self-service via Partner Center using GDK packaging. |
| **Worth using?** | **Yes for Windows reach.** Free individual developer accounts make it accessible. 88/12 revenue share is competitive. Certification can be a hurdle. Good discovery through Windows Search/Bing. |
| **Primary source** | [Free individual developer registration (Microsoft Learn)](https://learn.microsoft.com/en-us/windows/apps/publish/whats-new-individual-developer) · [PC game publishing via GDK](https://learn.microsoft.com/en-us/windows/apps/publish/whats-new-game-publishing) · [Developer account FAQ](https://learn.microsoft.com/en-us/windows/apps/publish/faq/open-developer-account) · [Windows Blog announcement](https://blogs.windows.com/windowsdeveloper/2025/09/10/free-developer-registration-for-individual-developers-on-microsoft-store/) |

## 6. Humble Store / Humble Games

| Attribute | Detail |
|-----------|--------|
| **Free to upload?** | **Free to apply** — submit via the [Developer Portal](https://www.humblebundle.com/developer). However, acceptance is **curated and selective**. |
| **Revenue share** | **75/25** in developer's favor (developer gets 75%). |
| **Annual / per-app fees** | None. |
| **Payment processing** | $250 min. payout threshold. Payments via check, direct deposit (US), PayPal, or wire ($15 fee). Humble holds 10% for refunds/chargebacks. |
| **Review process** | **Highly curated.** Submit, then Humble decides if your game fits the store. No guarantee. |
| **Worth using?** | **Only if selected.** Good for discovery via bundles and Humble Choice. Not a self-service platform. |
| **Primary source** | [Humble Store developer FAQ](https://support.humblebundle.com/hc/en-us/articles/202742080-Humble-Store-FAQ-For-Developers) · [Developer Resources](https://www.humblebundle.com/developer) · [Submission support article](https://support.humblebundle.com/hc/en-us/articles/204303718-Submitting-Your-Game-To-Humble-Bundle) |

## 7. IndieGala

| Attribute | Detail |
|-----------|--------|
| **Free to upload?** | **Yes.** Free developer account, unlimited games. Upload via the Developer Showcase. |
| **Revenue share** | **Pay-per-impression (PPI)** model: **$0.001 USD per page view**. Not traditional revenue share on sales. |
| **Annual / per-app fees** | None. |
| **Payment processing** | PPI earnings paid out periodically; advance possible ($200–$1,000 for qualifying projects). |
| **Review process** | **Minimal.** Upload freely to the Showcase section. No curation for standard listing. |
| **Worth using?** | **Limited.** The PPI monetization pays very little ($0.001 per view — $1 per 1,000 views). Small userbase. Good for hosting DRM-free builds and getting some visibility through their newsletter (1M+ subscribers). |
| **Primary source** | [IndieGala docs — For indie developers](https://docs.indiegala.com/dev_showcase/for_devs.html) · [Monetization (PPI) docs](https://docs.indiegala.com/dev_showcase/monetization.html) · [galaK upload tool](https://docs.indiegala.com/dev_showcase/galak.html) |

## 8. Other Notable Stores (No Upfront Fee)

### Newgrounds

| Attribute | Detail |
|-----------|--------|
| **Free to upload?** | **Yes.** Free account, upload HTML5 or SWF games. Max 2 submissions/day. |
| **Revenue share** | Ad revenue sharing (Ads on game pages). No direct sales model. |
| **Review process** | Community-based judging system. |
| **Worth using?** | **For browser games only.** Strong nostalgic community, good for exposure. Not suitable for downloadable PC games. |
| **Primary source** | [Newgrounds Wiki — Games and Movies](https://www.newgrounds.com/wiki/help-information/content-submission/games-and-movies) |

### Steam Direct

| Attribute | Detail |
|-----------|--------|
| **Free to upload?** | **No.** $100 USD one-time fee per game via Steam Direct (recoupable after $1,000 in sales). |
| **Revenue share** | 70/30 (75/25 after $10M, 80/20 after $50M). |
| **Worth using?** | Included as a baseline — this is the fee the user wants to avoid. |
| **Primary source** | [Steam Direct (Valve)](https://partner.steamgames.com/steamdirect) |

## Summary: Best Free Option

**itch.io** is the best platform if you want zero upfront cost, maximum developer control, and real audience reach. It has no submission fee, no annual fees, and you can set the platform's cut to 0% if you wish. It hosts the majority of major game jams (the #1 discoverability channel for indies), supports pay-what-you-want pricing, and has a mature audience willing to pay for indie games. For a free secondary upload, **Game Jolt** offers stronger community/social features and a younger audience.

| Platform | Free to upload? | Upfront cost | Best for |
|----------|----------------|--------------|----------|
| **itch.io** | Yes | $0 | Primary indie storefront; game jams; paid and free games |
| **Game Jolt** | Yes | $0 | Secondary; community-driven/browser games; younger audience |
| **GOG** | Apply only | $0 (curated) | Polished DRM-free games (if accepted) |
| **Epic Games Store** | No | $100/title (recoupable) | High-quality titles after you have budget |
| **Microsoft Store** | Yes (individual) | $0 (individual) | Windows audience reach |
| **Humble Store** | Apply only | $0 (curated) | If selected for bundles/store |
| **IndieGala** | Yes | $0 | DRM-free hosting; PPI earnings (very low) |
| **Newgrounds** | Yes | $0 | Browser games only |
